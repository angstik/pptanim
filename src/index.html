2. Découpage

3. Effet

Pour chaque lettre, une série est tirée au hasard. Saisie des emoji : touche Windows + point (Windows) ou Ctrl + Cmd + Espace (Mac).

La diapo animée est insérée juste après l'originale, qui n'est pas modifiée.
